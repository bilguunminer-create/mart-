## Нөхцөлөөс хамаарах болон жижиг асуудлууд

- **Express байршуулалтад P1:** `server.ts:101–125` дахь branding upload нэвтрэлтгүйгээр logo/banner файл бичдэг. Vercel-ийн `api/` дотор ижил endpoint байхгүй тул өнөөгийн Vercel сайтад ил гарсан гэж дүгнээгүй.
- Каталогт 4 худалдан авч болох бараа байхад ангиллын тоолуур нийтлэгдээгүй барааг тоолж байна. `CategoryBentoGrid.tsx:70` нь `published`/stock_quantity шалгахгүй. Онцлох Gochujang каталогийн хайлтад гарахгүй атлаа баннерт харагдана; `App.tsx:1299` нь нийтлэгдсэн/үлдэгдэлтэй эсэхийг шалгахгүй.
- “Үнэгүй И-мэйл OTP, нууц үг шаардахгүй” баннертай боловч бодит нэвтрэх цонх нууц үг шаардаж байна. Браузерт баталсан; `App.tsx:1320` орчмын тайлбарыг бодит урсгалтай нийцүүлэх.
- Профайлын mapper захиалгын `order_number`-ийг орхидог; дахин ачаалсны дараа баримтын дугаар өөр харагдаж болно. Хүргэлтийн сонголтыг бүх захиалгад Даланзадгад гэж нөхдөг. `UserProfileModal.tsx:102`, `App.tsx:278`.
- Захиалгын амжилтын дэлгэц дэх `completedOrder` төлбөрийн шинэ төлөвтэй синхрончлогдохгүй тул админ баталгаажуулсны дараа хэвлэх товч нээгдэхгүй байж болно. `CheckoutModal.tsx:180,289`.
- Production `/api/health` chatbot-ийн тохиргоог тайлагнахгүй. `smtpConfigured:true` нь имэйл амжилттай хүрснийг батлахгүй, зөвхөн тохиргоо байгааг илэрхийлнэ.
- Admin/inventory service worker ижил root scope-д бүртгэгддэг; админы worker inventory cache-ийг устгаж болзошгүй. `src/main.tsx:16`, `public/admin-sw.js:43`. Суурилуулсан төхөөрөмж дээр туршаагүй.
- Build амжилттай боловч үндсэн JavaScript 913.32 kB (gzip 262.69 kB), inventory chunk 477.38 kB; удаан гар утасны сүлжээнд хурд хэмжих тусдаа шалгалт хэрэгтэй.

## Хязгаар ба санал болгож буй дараалал

Бодит захиалга, төлбөр, OTP имэйл, support мессеж, push мэдэгдэл үүсгээгүй; үйлдвэрлэлийн өгөгдлийг өөрчлөөгүй. Нэвтэрсэн хэрэглэгч/админы бүрэн урсгал, бодит төлбөр, имэйл хүрэлт, төхөөрөмжийн камер/push/PWA-г end-to-end батлаагүй. Production сайт браузерт navigation timeout өгсөн тул түүний UI ажиллагааг HTTP 200-тай андуураагүй; live файлын харьцуулалтыг зөвхөн deployment зөрүүг батлахад ашигласан. Vercel connector энэ төслийн эрхгүй тул private log/env шалгаагүй.

1. Агуулахын anonymous execute эрх болон функц доторх staff authorization-ийг засах.
2. Цуцлалт/expiry-ийн үлдэгдэл, оноо буцаалтыг нэг transaction-д нэгтгэх.
3. Каталог хадгалалтыг зэрэгцээ шинэчлэлд тэсвэртэй болгох; checkout pending guard + тогтвортой request ID нэмэх.
4. Төлбөрийн дансны мэдээллийг бүрэн болгох, сэтгэгдлийн moderation эрхийг хязгаарлах.
5. Түүх/утас/token/chat-ын асуудлуудыг засаж, тусгаарласан туршилтын орчинд бүрэн урсгал турших.
6. Чатбот болон Google Forms-ийн өөрчлөлтийг хамруулан deploy хийж, бодит сайтын браузерын шалгалтыг давтах.

Энэ аудит өөрөө засвар эсвэл deployment хийгээгүй. Өмнөх ажлын өөрчлөлтүүд хэвээр, зөвхөн `audit/` дахь тайлан, нотолгоо нэмэгдсэн.
